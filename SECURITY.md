# Security Policy

## Supported Versions
We generally support the latest main branch. For stable releases, check the repository tags.

## Reporting a Vulnerability
Please report security issues privately to:
- Benny Perumalla <benny01r@gmail.com>
- Irshad Siddi <mohammadirshadsiddi@gmail.com>

We aim to acknowledge and triage within 72 hours. Please do not disclose publicly until we confirm and release a fix.

## Guidelines
- Provide steps to reproduce and potential impact
- Include relevant logs or PoCs if available
- Avoid including sensitive data in reports

## Disclosure
Once a fix is available, we will publish a security advisory and credit the reporter if desired.
